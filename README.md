# Хякки: энциклопедия ёкаев

Небольшая энциклопедия японских ёкаев в тёмной японской хоррор-эстетике: демоны они, лисы-оборотни кицунэ и горные духи тэнгу.

- Фон: кровавая луна, тучи, туман и блуждающие огни, нарисованные одним WebGL-шейдером.
- Маски проявляются из темноты при прокрутке, вокруг них движутся дым и огоньки.
- Панель хвостов кицунэ и плитки фактов анимируются, когда появляются на экране.

Сайт состоит из одного файла `index.html` и трёх картинок в `assets/`. Сборка не нужна: достаточно открыть `index.html` в браузере.
