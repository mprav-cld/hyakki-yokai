# Хякки: онлайн-энциклопедия японских ёкаев

Сайт для продажи доступа к авторской онлайн-энциклопедии о японских ёкаях: они, кицунэ, тэнгу и другие духи.

Живая версия: https://mprav-cld.github.io/hyakki-yokai/

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная: оффер, что внутри, превью трёх статей, факты, как получить доступ, вопросы, форма заявки |
| `404.html` | Своя страница «не найдено» |
| `privacy.html` | Политика обработки персональных данных (шаблон) |
| `consent.html` | Согласие на обработку персональных данных (шаблон) |
| `assets/site.js` | Настройки сайта, уведомление о cookie, аналитика |
| `assets/site.css` | Общие стили: уведомление о cookie, 404, документы |
| `favicon.*`, `icon-*.png`, `apple-touch-icon.png`, `site.webmanifest` | Иконки сайта |
| `og-image.jpg` | Картинка для превью ссылки в соцсетях и мессенджерах |
| `robots.txt`, `sitemap.xml` | Для поисковиков |
| `docs/tracking-plan.md` | План аналитики: события, воронка, цели |

## Перед запуском

1. **Документы.** В `privacy.html` и `consent.html` замените выделенные поля в квадратных скобках: ФИО или наименование, ИНН или ОГРНИП, почту для обращений, срок хранения, сервисы.
2. **Форма заявки.** Сейчас она работает в демо-режиме: проверяет поля и показывает «Спасибо», но никуда не отправляет. Чтобы заявки приходили на почту, создайте форму в Formspree, Getform или похожем сервисе и вставьте её адрес в `formEndpoint` в `assets/site.js`. Форма отправляет JSON: `name`, `email`, `consent`, `page`, `sent_at`.
3. **Аналитика.** Впишите номер счётчика Яндекс Метрики в `yandexMetrikaId` и/или ID Google Analytics 4 в `ga4Id` в `assets/site.js`. Цели описаны в `docs/tracking-plan.md`.

Сборка не нужна: это статический сайт, GitHub Pages публикует его как есть.
