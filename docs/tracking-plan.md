# Хякки: план аналитики

Обновлено: 2026-10-19

## Инструменты

- Все события уходят в `window.dataLayer` (подходит для Google Tag Manager).
- Яндекс Метрика и Google Analytics 4 подключаются в `assets/site.js` (поля `yandexMetrikaId` и `ga4Id`) и загружаются только после того, как посетитель нажал «Принять» в уведомлении о cookie.
- Отправить событие из любого кода: `window.hyakki.track('event_name', { ... })`.

## Вопросы, на которые отвечает аналитика

1. Сколько посетителей доходит до формы и сколько из них оставляет заявку?
2. Какая кнопка «Хочу доступ» приводит больше всего заявок: в меню, на первом экране или после блока «Как получить доступ»?
3. На каком поле формы люди ошибаются и бросают её?
4. Какие вопросы из FAQ открывают чаще всего (сигнал, что ответ нужно поднять выше на странице)?

## События

| Событие | Когда срабатывает | Параметры | Цель |
|---|---|---|---|
| `cta_clicked` | клик по любой кнопке «Хочу доступ» или «Сначала посмотреть» | `location` (nav, hero, hero_preview, how), `button_text` | |
| `section_viewed` | раздел впервые виден на треть | `section` (inside, preview, facts, how, faq, order) | |
| `faq_opened` | открыт вопрос в FAQ | `question` | |
| `form_started` | первый фокус в форме заявки | `form` = order | |
| `form_error` | ошибка при отправке | `form`, `field` (name, email, consent, network) | |
| `lead_submitted` | заявка успешно отправлена | `form` = order | Конверсия. В GA4 уходит как `generate_lead` |
| `cookie_consent` | выбор в уведомлении о cookie | `choice` (all, necessary) | |
| `page_not_found` | открыта страница 404 | `path` | |

## Воронка

`section_viewed: inside` → `section_viewed: preview` → `section_viewed: order` → `form_started` → `lead_submitted`

## Настройка целей

- **Яндекс Метрика:** Цели → Добавить цель → «JavaScript-событие», идентификатор `lead_submitted`. Так же можно добавить `form_started` и `cta_clicked`.
- **GA4:** Администратор → События → отметить `generate_lead` как ключевое событие.

## UTM-метки

Ссылки на сайт из соцсетей и рассылок размечайте так: `?utm_source=telegram&utm_medium=social&utm_campaign=launch`. Пишите всё строчными буквами, слова разделяйте подчёркиванием.

## Персональные данные

Имя и почта из формы никогда не передаются в аналитику: в события попадают только названия полей и разделов.
